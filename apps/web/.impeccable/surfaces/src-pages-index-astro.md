# Landing (`/`)

## Scope

The entry page of the open-source project. Visitor mode: **Persuade**. It shares the theme of the editor (`src/styles/global.css`).

## Audience and action

Backend and full-stack developers deciding whether to try Design DB. The one action: **Abrir el editor** (`/app`). Secondary: the repository on GitHub (https://github.com/Freddyz5/design-db).

## Proof

A live demonstration with the project's own core: the visitor types SQL and the board updates. No screenshots, no invented users, numbers or testimonials. Claims allowed: open source, local, no account (the pilot keeps everything in the browser), SQL / DBML / Drizzle in both directions.
